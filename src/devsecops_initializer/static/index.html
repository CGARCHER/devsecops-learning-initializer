Inicializador DevSecOps

Prepara controles de seguridad para un proyecto Spring Boot existente.

Perfil disponible: Spring Boot

¿Qué hace esta herramienta?

Analiza la estructura de un proyecto, explica los controles que puede incorporar y genera una copia en formato ZIP. El proyecto que subas no se modifica.

  1. Selecciona los controles.
  2. Carga y analiza el proyecto.
  3. Revisa los archivos.
  4. Descarga la copia.
1

Antes de utilizar el dashboard

  1. Crea un token de GitHub con permisos Actions: Read y Contents: Read.
  2. Guárdalo en .devsecops/secrets/github_token.txt.
  3. Indica propietario/repositorio en .devsecops/dashboard.env.

La IA ya está desplegada y no requiere configurar modelos. Consulta docs/devsecops/dashboard.md para ver todos los pasos.
